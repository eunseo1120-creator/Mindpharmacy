## 2026-07-29 / ideation.docx

### 확인된 핵심

- 약방을 중심 허브로 사용하는 3개 챕터 구조
- 유아기, 청소년기, 성인기의 순차적 기억 탐색
- 각 방을 네 방향으로 전환하는 포인트앤클릭 방식
- 감정 재료 획득과 약 조제
- 약사와 편지 주인의 동일 인물 반전
- 4:3 화면과 세로형 인벤토리 참고안

### 개발 영향

- 공통 RoomScene과 데이터 기반 챕터 구조가 필요함
- 유아기 챕터가 첫 세로 슬라이스에 가장 적합함
- 민감 콘텐츠 설정과 도움받기 화면이 필수임
- 1366, 117, 109 정보는 출시 전에 공식 출처 재검증이 필요함

### 반영 산출물

- 챕터 JSON Schema 초안
- 유아기 챕터 데이터 예시
- 콘텐츠 참조·완료 조건 검증 스크립트
- 데스크톱·태블릿·휴대전화 반응형 UI 명세
- 유아기 세로 슬라이스 MVP와 플랫폼별 검수 기준

### 보류된 항목

- 유아기 동화책의 전체 페이지 수와 퍼즐 4·5가 확정되지 않아 예시는 첫 두 페이지 중심으로 작성함
- 프로토타입에서는 색깔 블록을 오른쪽 방 바닥에서 획득하도록 임시 결정함
- 프로토타입 전화기는 숫자 버튼으로 `1366`을 입력하며, 본 제작에서 회전식 다이얼 조작으로 교체 가능함
