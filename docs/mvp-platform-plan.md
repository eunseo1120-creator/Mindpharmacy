# MVP와 플랫폼 검수 계획

## 첫 번째 세로 슬라이스

프롤로그, 약방, 유아기 방, 약 조제 귀환까지를 실제 배포 가능한 품질로 완성한다. 청소년기와 성인기를 일부만 구현한 상태는 MVP 완료로 보지 않는다.

## 포함 범위

- 타이틀
- 새 게임과 이어하기
- 설정
- 콘텐츠 경고
- 약방 편지함
- 유아기 편지
- 유아기 방 네 방향
- 확대 조사 화면
- 아이템 획득·선택·조합·사용
- 최소 4개의 연결된 퍼즐
- 3단계 힌트
- 1366 전화기 퍼즐
- 용기 감정과 문 열쇠
- 문 열기
- 약방 귀환과 약 조제
- 자동 저장과 불러오기
- 도움받기 정보

## MVP에서 제외

- 청소년기와 성인기 완성 콘텐츠
- 진실의 방과 최종 엔딩
- 다중 엔딩
- 계정과 클라우드 저장
- 온라인 순위
- 네이티브 앱 스토어 등록
- 음성 더빙

제외 항목은 구조적으로 확장 가능해야 하지만, 첫 구현 일정에 포함하지 않는다.

## 단계

### 1. 인터랙션 골격

- 4:3 반응형 캔버스
- 네 방향 전환
- 정규화 핫스폿
- 확대 모달
- 마우스·터치·키보드 입력

완료 조건: 임시 도형만으로도 모든 입력 방식에서 네 방향과 확대 화면을 오갈 수 있다.

### 2. 아이템과 퍼즐

- 인벤토리
- 조합
- 조건과 효과 실행기
- 힌트
- 퍼즐 완료 플래그

완료 조건: 곰인형 수선부터 동화책 페이지 획득까지 새로고침 없이 진행 가능하다.

### 3. 저장과 복원

- 자동 저장
- 저장 스키마 버전
- 손상된 저장 데이터 복구
- 새 게임 확인

완료 조건: 퍼즐 도중 게임을 닫고 다시 열어도 동일 장면·아이템·플래그가 복원된다.

### 4. 유아기 콘텐츠 통합

- 최종 배경과 오브젝트
- 사운드와 자막
- 전화기 퍼즐
- 문 열기
- 약방 귀환

완료 조건: 개발자 도구 없이 처음부터 약 조제까지 막힘 없이 플레이할 수 있다.

### 5. 플랫폼 안정화

- Godot 플랫폼별 Export Preset
- 터치 안전 영역
- 음향 자동재생 대응
- 백그라운드 복귀
- 저사양 이미지 메모리 관리

완료 조건: 아래 테스트 매트릭스의 필수 환경에서 진행 차단 문제가 없다.

## 필수 테스트 매트릭스

| 환경 | 입력 | 화면 | 필수 여부 |
|---|---|---|---|
| Windows 네이티브 빌드 | 마우스·키보드 | 1920×1080 | 필수 |
| macOS 네이티브 빌드 | 트랙패드·키보드 | 1440×900 이상 | 필수 |
| iPadOS 네이티브 빌드 | 터치 | 가로·세로 | 필수 |
| iPhone 네이티브 빌드 | 터치 | 가로·세로 | 필수 |
| Android 네이티브 빌드 | 터치 | 가로·세로 | 필수 |
| Web 빌드 최신 브라우저 | 마우스·터치 | 가로·세로 | 권장 |

출시 직전 운영체제와 Godot 버전을 다시 기록한다. 데스크톱 원격 디버깅이나 화면 에뮬레이션만으로 모바일 검수를 끝내지 않는다.

## 공통 합격 기준

- 장면이 잘리거나 비율이 변형되지 않는다.
- 모든 필수 기능을 터치만으로 완료할 수 있다.
- 모든 필수 기능을 마우스로 완료할 수 있다.
- 키보드만으로 설정과 주요 퍼즐을 조작할 수 있다.
- 오디오가 재생되지 않아도 정보가 손실되지 않는다.
- 전환 영상 스킵이 진행 상태를 망가뜨리지 않는다.
- 백그라운드 복귀 후 사운드가 중복 재생되지 않는다.
- 저장 중 종료해도 이전 정상 저장을 읽을 수 있다.
- 150% 글자 크기에서 버튼·대사가 잘리지 않는다.
- 화면 흔들림 감소 설정이 모든 챕터 전환에 적용된다.

## 성능 목표

- 첫 화면이 일반적인 모바일 네트워크에서 가능한 한 빠르게 표시될 것
- 타이틀 진입 전에 전체 챕터 자산을 받지 않을 것
- 장면 전환 중 로딩이 필요하면 진행률 또는 의도된 전환을 표시할 것
- 하나의 배경을 중복 파일명으로 복제하지 않을 것
- 완료한 챕터의 불필요한 텍스처와 오디오를 메모리에서 해제할 것

실제 수치 목표는 첫 아트 자산 세트의 크기를 측정한 뒤 확정한다.

## 출시 전 콘텐츠 검수

- 전화번호와 기관명이 공식 정보와 일치하는가?
- 콘텐츠 경고가 실제 장면보다 축소되어 있지 않은가?
- 피해자를 탓하거나 폭력을 성장 장치로 미화하지 않는가?
- 도움 요청이 실패나 나약함으로 묘사되지 않는가?
- 긴급 상황과 일반 상담 경로가 구분되는가?
- 전문가 또는 관련 기관의 감수를 받았는가?

## MVP 착수 전에 확정할 결정

1. 유아기 방의 최종 네 방향 배치
2. 블록 세트를 얻는 위치와 행동
3. 동화책의 총 페이지 수
4. 전화 다이얼의 조작 방식
5. 용기 재료와 완성 약의 최종 이름
6. 임시 이미지로 개발을 시작할지, 1차 콘셉트 아트를 기다릴지
7. 첫 배포를 웹 링크로 할지 설치형 앱까지 포함할지
