# 마음 약방 게임 설계

## 핵심 경험

플레이어는 문이 없는 약방의 약사다. 세 통의 편지를 통해 유아기, 청소년기, 성인기의 기억 공간으로 들어가 퍼즐을 풀고 긍정적인 감정을 회복한다. 마지막에는 약사와 편지의 주인이 동일 인물이었다는 사실을 마주하고, 모은 감정으로 마음의 열쇠를 만들어 현실로 나간다.

## 플레이 루프

1. 약방에서 빛나는 편지를 발견한다.
2. 편지를 열어 사연의 핵심 문장을 읽는다.
3. 짧은 장면 전환 후 기억의 방으로 진입한다.
4. 좌·정면·우·후면 네 방향을 탐색한다.
5. 오브젝트를 조사하고 아이템을 수집·조합한다.
6. 단서의 의미를 연결해 최종 퍼즐을 해결한다.
7. 감정 재료와 출구 열쇠를 획득한다.
8. 약방으로 돌아와 약을 조제한다.
9. 세 챕터가 끝나면 진실의 방과 엔딩이 열린다.

## 챕터 구조

### 프롤로그 — 문이 없는 약방

- 플레이 목적과 클릭 문법을 안전하게 학습한다.
- 편지함, 편지, 조제대가 핵심 상호작용 대상이다.
- 강한 공포 연출 없이 하이라이트와 확대 팝업을 소개한다.

### 1장 — 거대한 두려움의 방

- 주제: 가정폭력으로 인한 무력감과 두려움
- 핵심 오브젝트: 그림일기, 곰인형, 장난감 기차, 동화책, 전화기
- 핵심 감정: 용기
- 대표 퍼즐 흐름:
  - 책꽂이 정리 → 그림일기 획득
  - 바늘+실 → 곰인형 수선 → 동화책 페이지
  - 블록 배열 → 기차 수리 → 동화책 페이지
  - 흩어진 페이지 조합 → 완성된 동화책
  - 단서 확인 → 1366 입력 → 용기와 열쇠 획득

### 2장 — 시선이 메아리치는 교실

- 주제: 학교폭력과 또래의 시선
- 핵심 오브젝트: 낙서 책상, 사물함, 실내화, 일기장, 테이프, 칠판
- 핵심 감정: 굳은 의지
- 대표 퍼즐 흐름:
  - 낙서 해독 → 사물함 암호
  - 실내화 조각 복원 → 추가 단서
  - 테이프 조각+미로 → 117
  - 칠판에 117 입력 → 환청 종료, 감정과 열쇠 획득

### 3장 — 심해로 가라앉은 방

- 주제: 실패, 비교, 우울, 고립
- 핵심 오브젝트: 모니터, 멀티탭, 야광 별, 꿈의 노트, 스마트폰, 티켓
- 핵심 감정: 자존감 또는 자기 긍정
- 대표 퍼즐 흐름:
  - 모니터 전원 차단 → 야광 단서 발견
  - 쓰레기 더미 탐색 → 꿈의 노트와 티켓
  - 휴대전화 세척·잠금 해제 → 일기 앱
  - 티켓을 손상된 사진에 결합 → 109
  - 전화 연결 → 물소리 제거, 감정 획득, 출구 노출

### 피날레 — 진실의 방

- 편지함이 비고 배경음이 사라진다.
- 거울에 과거의 세 모습이 겹쳐 보인다.
- 세 감정을 조합해 마음의 열쇠를 만든다.
- 없었던 문이 나타나고 현실의 방으로 이어진다.

## 플레이 원칙

- 시간 제한과 게임 오버는 사용하지 않는다.
- 중요한 아이템은 영구적으로 잃어버릴 수 없다.
- 정답 입력 실패는 처벌보다 시청각 피드백으로 알린다.
- 핫스폿은 기본 상태에서는 과도하게 반짝이지 않는다.
- 일정 시간 진전이 없으면 3단계 힌트를 선택적으로 제공한다.
- 챕터 사이에는 언제든 설정과 나가기 메뉴에 접근할 수 있다.

## 힌트 3단계

1. 관찰 방향: “책꽂이 옆의 표시를 다시 살펴보자.”
2. 관계 안내: “표시의 색과 책등의 색이 연결된 것 같다.”
3. 행동 안내: “키 표시의 높이 순서대로 책을 배열하자.”

## 콘텐츠 안전

- 시작 전에 가정폭력, 학교폭력, 우울 및 심리적 위기에 관한 콘텐츠 경고를 표시한다.
- 화면 흔들림, 번쩍임, 속삭임·비명 효과를 각각 줄이거나 끌 수 있게 한다.
- 전화번호는 퍼즐 정답과 별개로 실제 용도를 명확히 설명한다.
- 엔딩과 일시정지 메뉴에 도움받기 화면을 둔다.
- 실제 폭력 장면의 직접 묘사보다 흔적, 소리, 왜곡된 공간을 활용한다.
- 번호와 기관 정보는 출시 직전에 공식 출처로 다시 검증한다.

## 아직 확정할 항목

- 주인공의 이름, 나이와 시간 간격
- 각 편지의 최종 원문
- 유아기 퍼즐 4·5의 완결
- 청소년기와 성인기 방의 정확한 4방향 배치
- 각 챕터에서 감정 재료와 완성 약의 이름
- 엔딩 독백의 최종 문구
- 일반 엔딩 외 다른 결말의 존재 여부
