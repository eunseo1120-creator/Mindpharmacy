# 반응형 UI 명세

## 방향

Rusty Lake 계열에서 참고할 요소는 정적인 회화형 장면, 화면 가장자리 이동, 제한된 인벤토리, 오브젝트 확대, 절제된 피드백이다. 고유 그림체와 프레임은 복제하지 않고, 마음 약방의 따뜻하지만 불안한 드림코어 분위기에 맞는 별도 시각 언어를 사용한다.

## 논리 캔버스

- 게임 장면 기준: 1600×1200, 4:3
- 월드 좌표: 항상 1600×1200
- 실제 출력: 화면 안에서 비율을 유지한 채 최대 확대
- 남는 영역: 짙은 갈색·먹색 계열 레터박스
- 게임 플레이 중 임의 크롭 금지
- 확대 이미지는 원 장면 위 모달 레이어로 표시

## 데스크톱·태블릿 가로 배치

```text
┌────────────────────────────────────────────────────────┐
│ [설정]                                      [힌트]      │
│ ┌──────────────────────────────────────┐ ┌────────────┐ │
│ │                                      │ │ 인벤토리 1 │ │
│ │                                      │ ├────────────┤ │
│ │             4:3 장면                 │ │ 인벤토리 2 │ │
│ │                                      │ ├────────────┤ │
│ │                                      │ │ 인벤토리 3 │ │
│ │ [이전 방향]                [다음 방향]│ ├────────────┤ │
│ └──────────────────────────────────────┘ │ 스크롤     │ │
│                                          └────────────┘ │
└────────────────────────────────────────────────────────┘
```

- 인벤토리는 장면 오른쪽에 둔다.
- 장면 자체의 4:3은 인벤토리 공간을 제외하고 계산한다.
- 화살표는 장면 좌우 중앙에 두되 중요한 핫스폿을 가리지 않는다.
- 포인터가 게임 영역을 벗어나도 선택 아이템 상태를 유지한다.

## 휴대전화 가로 배치

```text
┌──────────────────────────────────────────┐
│ [설정]              장면          [힌트] │
│                                          │
│ [◀]               4:3                 [▶]│
│                                          │
├──────────────────────────────────────────┤
│  아이템 1 │ 아이템 2 │ 아이템 3 │  …    │
└──────────────────────────────────────────┘
```

- 인벤토리는 하단 가로 스크롤로 바뀐다.
- 브라우저 주소창 변화를 고려해 `100dvh`를 사용한다.
- 안전 영역은 `env(safe-area-inset-*)`로 확보한다.
- 두 손가락 확대는 막지 않되, 게임 장면의 드래그 이동으로 오인하지 않는다.

## 휴대전화 세로 배치

세로 플레이도 막지 않지만 권장하지 않는다.

- 상단에 4:3 장면을 최대 너비로 배치한다.
- 하단에 인벤토리, 현재 아이템 설명, 회전 권장 안내를 둔다.
- 회전을 강제하지 않는다.
- 편지와 긴 문서는 세로 화면에서 화면 높이의 80%까지 확대 가능하게 한다.

## UI 영역 우선순위

1. 장면과 퍼즐 입력
2. 선택된 아이템
3. 방향 전환
4. 인벤토리
5. 설정과 힌트

작은 화면에서는 장식 프레임을 먼저 줄이고, 클릭 대상과 본문 크기는 유지한다.

## 공통 구성요소

### 방향 버튼

- 좌우 화면 가장자리 중앙에 배치
- 터치 영역 최소 48×64 CSS px
- 시각 아이콘보다 터치 영역을 넓게 설정
- 누름, 비활성, 포커스 상태 필요
- 장면 전환 중 연속 입력 방지

### 인벤토리 슬롯

- 기본, 보유, 선택, 조합 가능, 사용 불가 상태
- 선택 아이템 이름을 화면에 텍스트로 표시
- 빈 슬롯을 불필요하게 많이 노출하지 않는다.
- 아이템이 많으면 데스크톱은 세로, 모바일은 가로 스크롤
- 드래그 외에 “선택 후 대상 클릭”도 지원

터치 환경에서 정밀 드래그만 요구하면 접근성과 조작 안정성이 떨어지므로 두 방식은 같은 결과를 내야 한다.

### 핫스폿

- 기본 상태에서는 보이지 않거나 아주 약한 환경 애니메이션만 사용
- 처음 배우는 상호작용과 막힌 상태에서만 선택적 하이라이트
- 마우스: 커서 변화와 짧은 시각 피드백
- 터치: 누른 위치에 잔물결 또는 짧은 수축 효과
- 오답 클릭에도 무반응 대신 짧은 관찰 문장 제공 가능

### 확대 모달

- 배경을 55~70% 어둡게 처리
- 확대 콘텐츠는 원본 4:3 안에서 최대 크기로 표시
- 닫기 버튼, 바깥 영역 클릭, `Esc` 모두 지원
- 모달이 열리면 뒤쪽 핫스폿 입력 중단
- 키보드 포커스를 모달 안에 가둔다.

### 편지

- 첫 진입 시 핵심 문장만 보여주고 스크롤 또는 다음 버튼으로 전체 공개
- 문장 아래를 단순 페이드로 가릴 때도 스크린 리더에는 전체 텍스트 제공
- 글자 크기 조절 시 종이 이미지에 글자를 합성하지 않고 별도 텍스트 레이어 사용

### 전화기 퍼즐

- 다이얼을 직접 회전시키는 조작과 숫자 버튼 대체 입력을 모두 지원
- 입력된 번호는 시각적으로 확인 가능해야 한다.
- 잘못된 번호는 초기화하되 공포음으로 처벌하지 않는다.
- 정답 후 실제 번호의 용도를 설명하는 정보 카드를 제공한다.

## 시각 상태 토큰

```text
--color-ink:        #211b19
--color-paper:      #d8c7a2
--color-pharmacy:   #82684f
--color-glow:       #e9c66d
--color-danger:     #8b4039
--color-focus:      #f0d98c
--overlay-dim:      rgba(15, 12, 11, 0.68)

--motion-fast:      120ms
--motion-normal:    240ms
--motion-scene:     700ms
--radius-control:   6px
--focus-width:      3px
```

이 값은 초기 토큰이며 실제 콘셉트 아트 이후 조정한다. 정보 전달을 색 하나에만 의존하지 않는다.

## 애니메이션

- 일반 전환: 500~700ms 페이드
- 획득: 240ms 축소 후 인벤토리 방향 이동
- 하이라이트: 1.8~2.4초의 느린 밝기 변화
- 정답: 짧은 빛과 사운드, 상태 변화
- 화면 흔들림: 기본 최대 400ms, 강도 제한
- `reducedMotion`에서는 이동·흔들림을 제거하고 150ms 교차 페이드로 대체

영상 전환은 스킵 가능해야 하며, 스킵 후에도 필수 플래그와 아이템 상태가 동일해야 한다.

## 입력 매핑

| 행동 | 마우스 | 터치 | 키보드 |
|---|---|---|---|
| 조사 | 클릭 | 탭 | Enter/Space |
| 방향 이동 | 화살표 클릭 | 화살표 탭 | 좌/우 방향키 |
| 아이템 선택 | 슬롯 클릭 | 슬롯 탭 | Tab 후 Enter |
| 아이템 사용 | 드래그 또는 선택 후 클릭 | 드래그 또는 선택 후 탭 | 대상 포커스 후 Enter |
| 모달 닫기 | 닫기/바깥 클릭 | 닫기/바깥 탭 | Esc |
| 설정 | 버튼 클릭 | 버튼 탭 | Esc 메뉴 |

## 접근성 필수 설정

- 전체 자막
- BGM과 효과음 개별 음량
- 화면 흔들림 감소
- 번쩍임 제거
- 강한 공포음 감소
- 글자 크기 100%·125%·150%
- 고대비 포커스
- 드래그 대체 입력
- 영상 건너뛰기

## 화면별 상태 목록

각 화면은 최소한 아래 상태를 시각 자산 또는 런타임 레이어로 구분한다.

- 최초 진입
- 상호작용 가능
- 아이템 선택
- 퍼즐 진행 중
- 퍼즐 해결 후
- 챕터 완료
- 모달 열림
- 설정 열림
- 저장 중·저장 완료
- 로딩 실패
