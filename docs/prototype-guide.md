# Godot 프로토타입 안내

## 실행

1. Godot 4.7.1 이상에서 프로젝트 폴더의 `project.godot`을 연다.
2. 프로젝트 실행 버튼 또는 `F6`이 아닌 `F5`를 누른다.
3. 첫 화면에서 빛나는 편지함을 누른다.

## 현재 플레이 경로

1. 약방의 편지함을 연다.
2. 기억의 방으로 이동한다.
3. 뒤쪽에서 바늘과 실을 얻는다.
4. 오른쪽에서 뜯어진 곰인형과 색깔 블록을 얻는다.
5. 아이템 조합으로 곰인형을 수선한다.
6. 왼쪽 책꽂이에서 그림일기를 확인한다.
7. 수선된 곰인형을 선택하고 침대 밑을 누른다.
8. 오른쪽 기차에 색깔 블록을 사용해 두 번째 페이지를 얻는다.
9. 동화책 두 페이지를 조합한다.
10. 정면 전화기에 `1366`을 입력한다.
11. 열쇠를 선택하고 거대한 문을 연다.
12. 약방 조제대를 눌러 물약을 완성한다.

## 프로젝트 구조

```text
project.godot                 Godot 프로젝트 설정
export_presets.cfg           플랫폼별 내보내기 초안
scenes/main.tscn             시작 장면
scripts/game.gd              게임 상태와 UI·상호작용
scripts/room_art.gd          임시 배경과 오브젝트 그림
scripts/save_manager.gd      로컬 자동 저장
content/                     장기적으로 사용할 데이터 기반 콘텐츠
docs/                        기획·UI·플랫폼·자산 문서
tools/                       콘텐츠와 Ideation 검증 도구
```

현재 `game.gd`는 팀이 한 파일에서 전체 흐름을 쉽게 읽을 수 있도록 의도적으로 묶어 두었다. 본 제작에서는 아래 순서로 분리한다.

- `scenes/pharmacy/`
- `scenes/rooms/`
- `systems/inventory/`
- `systems/puzzles/`
- `systems/save/`
- `ui/`
- `content/chapters/*.json`

## 프로토타입의 임시 요소

- 모든 그림은 `room_art.gd`에서 그리는 도형 기반 임시 아트다.
- 사운드와 전환 영상은 포함하지 않았다.
- 힌트는 각 진행 단계당 한 문장이다.
- 모바일은 동일한 반응형 화면을 사용하지만 실제 기기 QA는 별도로 필요하다.
- 내보내기에는 각 플랫폼의 Godot Export Template이 필요하다.

## 조작

- 마우스·터치: 버튼과 오브젝트 선택
- 좌우 방향키: 방 방향 전환
- `Esc`: 열린 팝업 닫기
- 아이템: 한 번 눌러 선택하고 장면의 대상 클릭

## 개발 검증

Godot 실행 파일이 PATH에 등록되어 있다면:

```bash
godot --headless --path . --script res://tests/smoke_test.gd
node tools/validate-content.mjs
```

스모크 테스트는 약방의 편지를 연 뒤 유아기 퍼즐 전체를 해결하고 물약을 완성할 때까지의 상태 변화를 확인한다.

## 참고 원칙

Rusty Lake의 중앙 정적 장면, 화면 가장자리 이동, 세로 인벤토리와 확대 조사 방식만 장르 문법으로 참고했다. 원작의 아트, 아이콘, 캐릭터, 음원, 문구와 퍼즐은 포함하지 않았다.
